# openspec-spec-probe для GigaCode: полный цикл v3

Скопируйте содержимое `agents/` в `.gigacode/agents/` проекта, а `spec-probe/` — в `.gigacode/spec-probe/`. Объединяйте каталоги, сохраняя другие файлы. Требуется Python 3. Проверьте регистрацию через `/agents manage`; при необходимости начните новую сессию.

```text
project/
  .gigacode/agents/openspec-spec-probe.md
  .gigacode/spec-probe/
  specs-repo/openspec/changes/my-change/
  src/api/
  src/web/
```

Достаточно одного запроса:

> Вызови openspec-spec-probe для my-change. Описание задачи: <ссылка Jira>; дополнительный контекст: <ссылка Confluence, если есть>. Выполни полный цикл с тремя независимыми реализациями.

Агент определяет каталоги, собирает источники, готовит конфигурацию и запускает runner. Не нужны MODE, PACKAGE_DIR, OUT_DIR или ручной compare. Можно запускать из корня рабочего проекта или вложенной папки: change может находиться в отдельном store. При нескольких подходящих change агент уточнит выбор.

Reverse видит код и подготовленные описания Jira/Confluence/других источников, но не исходный change, его копии и пересказы. Требования источников и подтверждённое поведение разделяются. Координатор и compare видят change.

**Однократная интеграция:** для реальной генерации нужен адаптер к установленному GigaCode и изолированному runtime по [ADAPTER.md](spec-probe/ADAPTER.md). Runner и контракт готовы, проверенного адаптера GigaCode в пакете нет; GigaCode отсутствует в среде разработки. Без адаптера агент сообщает конкретный блокер, не заставляет пользователя запускать этапы вручную и не выдаёт изоляцию за обеспеченную. Это оставшийся этап интеграционного пилота.

Внутренняя команда, которую выполняет координатор:

```sh
python3 .gigacode/spec-probe/scripts/runner.py my-change
```

Для диагностики подготовки без генераций: добавить `--prepare-only`. Источники и scope нужно разрешить до подготовки. Результаты полного цикла: `.spec-probe/<run-id>/result/report.md` и `report.json`; при ошибке — manifest.json с причиной и сохранённые промежуточные результаты.

Локальные проверки комплекта:

```sh
python3 -m unittest discover -s .gigacode/spec-probe/tests -v
```
